### Algorithm — Longest Valid Parentheses

1. Initialize a stack with `-1` and set `max_len = 0`.
2. Traverse the string using index `i`.
3. If the character is `(`, push its index into the stack.
4. If the character is `)`, pop the top index.
5. If the stack becomes empty, push the current index as a new starting point.
6. Otherwise, calculate the valid length as `i - stack[-1]`.
7. Update `max_len` with the maximum length.
8. Return `max_len`.

**Time:** `O(n)`
**Space:** `O(n)`
